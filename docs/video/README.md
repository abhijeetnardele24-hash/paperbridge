# PaperBridge demo video source

The narration is generated from `narration.ssml` with the locally installed Microsoft Heera English (India) system voice. The visual track uses only deterministic screenshots captured by the repository's Playwright suite. No real applicant data appears in the video.

The final rendered artifact is written to `artifacts/PaperBridge-Demo.mp4` and is intentionally ignored by Git because it is a submission upload rather than source material.
